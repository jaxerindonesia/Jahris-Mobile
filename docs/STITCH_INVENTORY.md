## Tidak tersedia sebagai screen khusus

Stitch tidak menyediakan screen khusus untuk Tugas, Reimburse, Payroll, Cabang,
Notifikasi, Profil, menu hamburger, serta Konfigurasi Kehadiran. Screen tersebut
dibuat mengikuti token dan pola visual dashboard serta ditandai `TODO-DESIGN` di
kode agar mudah diselaraskan jika desain resminya tersedia.
